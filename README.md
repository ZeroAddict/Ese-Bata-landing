## 📌 The Product (In Context)

Ese-Bata is a **portfolio project** demonstrating:

- **Frontend:** A scroll-snap landing page showcasing brand identity, features, and product videos
- **Backend (separate repo):** A functional e-commerce server with user authentication, product CRUD, and MVC architecture

**My Role:** Product lead, frontend designer/developer, backend developer

---

## 🎨 Frontend Features

| Feature | Description |
|---------|-------------|
| Scroll-snap sections | Smooth, modern UX for storytelling |
| Brand identity | Custom logo, color scheme, value proposition |
| Responsive layout | Designed for desktop first (mobile improvements ongoing) |
| Video demos | Embedded walkthroughs of the product concept |
| Deployed button | One-click access to the live landing page |

**Tech Stack:** HTML5, CSS3 (native, no frameworks), GitHub Pages deployment

---

## 🛠 Backend Overview (Separate Repo)

Built with:

**Key backend features:**
- User registration and authentication
- Product creation, retrieval, update, deletion
- Secure data persistence with MongoDB
- Async, non-blocking I/O via Node.js event loop
